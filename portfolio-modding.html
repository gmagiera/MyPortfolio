Project information

  • Category: Modding
  • Date: 2021 - today
  • Tools: NifSkope, Outfit Studio, BSA Unpacker, xEdit, CreationKit, Canva
  • Link: > Nexus Mods profile <

Game modding was my first introduction to game development and allowed me to shape games according to my own vision. I started with map editors in strategy games and train simulators, and later moved on to exploring the Construction Set and Creation Kit tools used in Bethesda games. These were initially small, personal modifications created for my own use.

This changed when I could not find any modification that added a poncho to Fallout 4. Based on my existing skills, I decided to create such a mod myself. To achieve this, I used two existing in-game clothing models - rags and a leather harness - and combined them using community-developed outfit editing tools. I then configured and implemented the new outfit in-game and published the mod.

My creation was well received by the community, and in response to user feedback I created additional color variants. Later on, I also added two hats inspired by iconic Wild West characters, both based on existing in-game models.
