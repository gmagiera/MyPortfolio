A community-driven tool created for players of the browser-based game BloodWars, designed to solve the complexity of the game's item-combination system. Each item consists of a base, prefix, and suffix, and the outcome of combining items depends on all possible permutations of these components, making the problem highly computation-heavy.

The goal of this project was twofold: to explore the feasibility of implementing a high-performance, computation-intensive system in Unity, and to provide players with a dynamic, real-time preview of all possible item outcomes - a feature not available in other community tools at the time.

The tool supports multiple game servers and multiple language data sets, including the English version of the game, which was added based on community feedback.

Due to the real-time preview design and Unity's single-threaded constraints, performance is currently the main limitation. I have a plane for future improvements, including implementation of a multi-threading and parallel processing to optimize computation time.
